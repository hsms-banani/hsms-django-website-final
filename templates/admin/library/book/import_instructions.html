CSV Import Instructions for Books

Follow these guidelines to ensure your CSV file is imported correctly.

General Instructions:

  • The CSV file must be in UTF-8 format, especially if it contains Bangla text.
  • The first row of the CSV must be the header row with the exact column names listed below.
  • Fields marked with an asterisk (*) are required.
  • You can download a template CSV file to get started.

Column-wise Instructions:

Column Name Required Data Type Description & Rules
title Conditional Text The main title of the book. Required if 'title_bangla' is empty.
title_bangla Conditional Text The title of the book in Bangla. If the 'title' column is empty, this value will be used as the main title.
author* Yes Text The full name of the author. For multiple authors, separate them with a semicolon (;). For example: Author One; Author Two.
publisher* Yes Text The name of the publisher.
publication_year* Yes Integer The year the book was published (e.g., 2023).
accession_number* Yes Text/Integer A unique identifier for each book. This must be unique across all books in the library.
category* Yes Text The category of the book (e.g., Fiction, History).
pages No Integer The number of pages in the book. If the page number is in a complex format like 'i-viii, 94', the importer will attempt to extract the main page number (94 in this case).
language No Text The language of the book (e.g., en, bn). Defaults to 'en' if not provided.
total_copies No Integer The total number of copies of the book. Defaults to 1.

Handling Bangla Books:

The system is designed to handle Bangla text properly. Here are some tips:

  • Encoding: Ensure your CSV file is saved with UTF-8 encoding. This is the most important step. In applications like Microsoft Excel, you can choose this encoding in the "Save As" dialog.
  • Fonts: You can use any standard Unicode Bangla font (like Nikosh, Kalpurush, or SolaimanLipi) to enter data in your CSV file. The system will store the text correctly regardless of the font you use.
  • Display: The admin panel and the public site will display Bangla text using appropriate fonts. If you see garbled text, it's likely an encoding issue with your CSV file.
